# 5. คู่มือการรันระบบและการใช้งานประจำวัน (System Execution & Operations Guide)
## ระบบบริหารเวลาปฏิบัติงานบุคลากร โรงพยาบาลสามชุก — Sam_Att V2 Standalone

เอกสารนี้อธิบายคำสั่งสำหรับรันระบบ **Sam_Att V2 Standalone** ทั้งในโหมดใช้งานจริง (`Production`) โหมดพัฒนาและศึกษาโค้ด (`Development`) การรันชุดทดสอบอัตโนมัติ รวมถึงขั้นตอนการใช้งานประจำวันสำหรับบุคลากรแต่ละระดับสิทธิ์

---

## 1. คำสั่งสำหรับรันระบบ (Command Reference)

เปิด Terminal หรือ PowerShell ในโฟลเดอร์หลักของโครงการ แล้วเลือกใช้คำสั่งตามวัตถุประสงค์ดังนี้:

| คำสั่ง | หน้าที่และการทำงาน |
| :--- | :--- |
| `npm run dev` | รันระบบในโหมดพัฒนา (`Development`) พร้อมโหลดการเปลี่ยนแปลงของโค้ดอัตโนมัติ |
| `npm run build` | คอมไพล์โค้ดหน้าเว็บ React + TypeScript (`frontend/src`) ออกมาเป็นไฟล์พร้อมใช้งานจริงในโฟลเดอร์ `dist/` |
| `npm start` | รันเซิร์ฟเวอร์หลัก (`server.ts`) เพื่อเปิดให้บริการทั้งหน้าเว็บ `/Sam_Att/` และ API `/api/Sam_Att/*` บนพอร์ต HTTPS `4101` |
| `npm run db:migrate` | รันสคริปต์สร้างหรืออัปเดตตารางฐานข้อมูลทั้ง 20 ตารางอย่างปลอดภัย |
| `npm run lint` | ตรวจสอบความถูกต้องของชนิดข้อมูล TypeScript ทั้งฝั่ง `backend/` และ `frontend/` |
| `npm test` | รันชุดทดสอบอัตโนมัติ 8 หมวด (ตรวจสอบพอร์ต 4101, ระบบล็อกอิน, RBAC 3 ระดับ, Anti-IDOR, การซิงก์ HOSOffice, สัญญาสแกน 6 ฟิลด์ และการคำนวณเวลา) |

## 2. ช่องทางเข้าใช้งานระบบ (URLs)

เมื่อรันเซิร์ฟเวอร์แล้ว ระบบจะเปิดให้บริการที่:
- **หน้าเว็บผู้ใช้งาน (Frontend SPA):**
  `https://localhost:4101/Sam_Att/` (หรือ `https://<IP-เครื่องแม่ข่ายโรงพยาบาล>:4101/Sam_Att/`)
- **จุดตรวจสอบสถานะระบบ (Health Check API):**
  `https://localhost:4101/api/Sam_Att/health`

## 3. บัญชีผู้ใช้งานเริ่มต้นสำหรับทดสอบ (ในโหมด Development / Sandbox)

ในสภาพแวดล้อมพัฒนาและทดสอบ (`NODE_ENV !== 'production'`) ระบบจะสร้างข้อมูลตัวอย่าง (ที่ไม่ใช่ข้อมูลส่วนบุคคลจริง) และบัญชีทดสอบครบทั้ง 3 ระดับสิทธิ์ให้พร้อมทดลองใช้งานทันที:

| ระดับสิทธิ์ | ชื่อผู้ใช้ (Username) | รหัสผ่าน (Password) | รหัสบุคลากรที่ผูก | ขอบเขตการใช้งาน |
| :--- | :--- | :--- | :--- | :--- |
| **ผู้ดูแลระบบ (`ADMIN`)** | `admin` | `Admin@SamAtt2026` | `SAM-P001` | เข้าได้ทุกเมนู จัดการผู้ใช้ เครื่องสแกน ตั้งค่าระบบ และอนุมัติอัปเดต |
| **เจ้าหน้าที่งานบุคคล (`RESPONSIBLE_STAFF`)** | `hrstaff` | `Staff@SamAtt2026` | `SAM-P002` | แดชบอร์ดองค์กร ตรวจเวลา Reprocess จัดเวร ซิงก์บุคลากร และออกรายงาน |
| **บุคลากรทั่วไป (`GENERAL_USER`)** | `user1003` | `User@SamAtt2026` | `SAM-P003` | ดูได้เฉพาะเวลาปฏิบัติงาน ตารางเวร และประวัติสแกนของตนเองเท่านั้น |
| **บุคลากรทั่วไป (`GENERAL_USER`)** | `user1004` | `User@SamAtt2026` | `SAM-P004` | ดูได้เฉพาะเวลาปฏิบัติงาน ตารางเวร และประวัติสแกนของตนเองเท่านั้น |

> **เคล็ดลับ:** บนหน้าจอเข้าสู่ระบบ (Login) มีปุ่มลัดสำหรับคลิกเติมชื่อผู้ใช้และรหัสผ่านของทั้ง 3 สิทธิ์ เพื่อความสะดวกในการทดสอบเปรียบเทียบหน้าจอ

## 4. ขั้นตอนการปฏิบัติงานประจำวัน (Daily Operational Workflows)

### 4.1 สำหรับเจ้าหน้าที่งานบุคคล (`RESPONSIBLE_STAFF`)
1. **ตรวจสอบภาพรวมประจำวัน:**
   - เข้าที่เมนู **"ภาพรวมองค์กร"** เลือกตัวกรองช่วงเวลาเป็น `รายวัน` หรือ `รายเดือน`
   - ตรวจสอบจำนวนผู้มาสาย ขาดสแกนเข้า หรือลืมสแกนออก (สามารถคลิกที่ตัวเลขหรือชื่อบุคลากรเพื่อเปิดดูรายละเอียดรายเวรได้ทันที)
2. **ซิงก์รายชื่อบุคลากรเมื่อมีเจ้าหน้าที่เข้าใหม่หรือย้ายแผนก:**
   - เข้าที่เมนู **"ทะเบียนบุคลากรและกะ"** คลิกปุ่ม **"ซิงก์ข้อมูลบุคลากรจาก HOSOffice"**
   - ตรวจสอบคอลัมน์สถานะรหัสสแกนนิ้ว หากพบรายการที่ยังไม่มี `FINGLE_ID` หรือรหัสซ้ำซ้อน ให้ประสานงานแก้ไขที่ทะเบียนประวัติ
3. **มอบหมายตารางเวรและจัดการกะทำงาน:**
   - เข้าที่เมนู **"จัดตารางเวรปฏิบัติงาน"** เพื่อมอบหมายเวรเช้า บ่าย ดึก หรือเวรข้ามวันให้บุคลากร
4. **ดึงข้อมูลสแกนและประมวลผลเวลาใหม่ (Reprocess):**
   - ระบบจะดึงข้อมูลจากเครื่องสแกนอัตโนมัติตามตารางเวลา (เช่น `00:00 น.` และ `08:00 น.`) หรือกดปุ่ม **"สั่งดึงข้อมูลจากเครื่องสแกนทันที"** ที่เมนูเครื่องสแกน
   - ในเมนู **"ตรวจสอบเวลาปฏิบัติงาน"** สามารถกด **"จำลองผลก่อนประมวลผล"** เพื่อดูผลกระทบก่อน แล้วกด **"ประมวลผลเวลาใหม่"**
5. **บันทึกหมายเหตุและตรวจทานรายการผิดปกติ:**
   - คลิกปุ่ม **"ตรวจสอบ / หมายเหตุ"** ในแถวหรือการ์ดของเวรที่มีสถานะ `มาสาย`, `ขาดสแกนเข้า` หรือ `ไม่สแกนออก`
   - บันทึกหมายเหตุชี้แจง (เช่น ไปราชการ, สลับเวร, เครื่องสแกนขัดข้อง) และปรับสถานะการตรวจทานของ HR เป็น `อนุมัติแล้ว` หรือ `อนุโลมตามระเบียบ`
6. **ส่งออกรายงานประจำเดือน:**
   - เข้าที่เมนู **"รายงานและสถิติการมาสาย"** เลือกงวดเดือนที่ต้องการ แล้วคลิก **"ดาวน์โหลดรายงาน CSV"** เพื่อนำไปใช้สรุปงานบริหารบุคคล

### 4.2 สำหรับบุคลากรทั่วไป (`GENERAL_USER`)
1. เข้าสู่ระบบผ่านคอมพิวเตอร์หรือโทรศัพท์มือถือ
2. ระบบจะแสดงหน้า **"เวลาปฏิบัติงานของฉัน"** โดยอัตโนมัติ
3. สามารถเลือกช่วงเวลาเพื่อตรวจสอบเวลาสแกนเข้า–ออกงาน นาทีสาย ตารางเวรที่ได้รับมอบหมาย และคลิก **"ดูหลักฐาน"** เพื่อดูเวลาสแกนนิ้วจริงและหมายเหตุจากฝ่ายบุคคลได้ทันที

## 5. การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

- **กรณีหน้าเว็บแจ้งเตือน `DB_UNAVAILABLE (503)`:**
  - ตรวจสอบว่าเซอร์วิส MySQL (`samchuk_attendance_v2`) กำลังทำงานอยู่ และค่า `SAM_ATT_DB_HOST`, `SAM_ATT_DB_USER`, `SAM_ATT_DB_PASSWORD` ในไฟล์ `.env` ถูกต้อง
- **กรณีซิงก์ข้อมูลจาก `HOSOffice` หรือ `ScannerReader.exe` แล้วแจ้งเตือน `FAIL_CLOSED`:**
  - ไปที่เมนู **"ตั้งค่าระบบและอัปเดต"** แล้วกดปุ่ม **"ทดสอบเชื่อมต่อ HOSOffice"** หรือ **"ตรวจสอบไฟล์ ScannerReader.exe"** เพื่อดูสาเหตุและพาธที่ตั้งค่าไว้
- **กรณีล็อกอินผิดเกิน 5 ครั้งจนบัญชีถูกล็อกชั่วคราว (`429 ACCOUNT_LOCKED`):**
  - ระบบจะปลดล็อกอัตโนมัติเมื่อครบกำหนดเวลา 15 นาที (ตามค่า `AUTH_RATE_LIMIT_WINDOW_MINUTES`)
